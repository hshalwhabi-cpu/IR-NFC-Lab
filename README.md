# IR & NFC Lab — تطبيق أندرويد للتحكم الكامل بالأشعة تحت الحمراء و NFC

تطبيق أصلي (Native Kotlin) بلا أي مكتبات خارجية، مصمّم لهاتف **HOTWAV Note 600 Pro**
(وأي هاتف أندرويد فيه باعث IR و NFC). يعطيك تحكمًا كاملًا:

## تبويب الأشعة تحت الحمراء (IR)
- **تشخيص العتاد**: هل يوجد باعث؟ ما الترددات المدعومة؟ وهل يوجد مستقبل للقراءة؟
- **إرسال بـ 11 بروتوكولًا جاهزًا**: NEC / NEC موسّع / Samsung / Sony SIRC (12/15/20) / RC5 / RC6 / JVC / Kaseikyo.
- **Pronto HEX**: الصق أي كود ريموت من الإنترنت وأرسله مباشرة، وحوّله من/إلى نمط خام.
- **نمط خام**: أدخل توقيتات الميكروثانية يدويًا.
- **مسح تلقائي**: يمسح نطاق أوامر كاملًا لاكتشاف كود جهاز مجهول (البديل العملي للقراءة).
- **ريموتات محفوظة**: احفظ الأزرار في ريموتات مخصصة، صدّرها/استوردها كـ JSON.

## تبويب NFC
- **قراءة كل شيء**: UID، ATQA/SAK، وكل التقنيات (NfcA/B/F/V، IsoDep)، مع Dump كامل
  لبطاقات MIFARE Classic (تجربة مفاتيح شائعة) و Ultralight، وقراءة رسائل NDEF.
- **كتابة NDEF**: نص، رابط، MIME، تشغيل تطبيق (AAR)، سجل خارجي — مع خيار **قفل نهائي**.
- **أوامر APDU خام**: أرسل أوامر IsoDep يدويًا (SELECT AID, READ BINARY, GET DATA...)
  واقرأ الرد مع تفسير رموز الحالة (SW).
- **محاكاة بطاقة (HCE)**: حوّل جوالك نفسه إلى بطاقة NFC يقرأها جهاز آخر.

## كيف تبنيه (خطوتان)

### الطريقة الأسهل — Android Studio
1. افتح Android Studio ← **Open** ← اختر مجلد `IR-NFC-Lab`.
2. اترك الاستوديو ينزّل الـ SDK والإضافات تلقائيًا (يحتاج إنترنت أول مرة).
3. وصّل الجوال (مع تفعيل *تصحيح USB*) ← اضغط **Run ▶**.

### من سطر الأوامر
```bash
# يتطلب Android SDK مثبّتًا ومتغيّر ANDROID_HOME مضبوطًا
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```
ثم ثبّت الـ APK: `adb install app/build/outputs/apk/debug/app-debug.apk`

> ملاحظة: لم يُبنَ الـ APK جاهزًا لأن بيئة الإنشاء هنا محجوبة عن خوادم Google/Maven،
> لكن المشروع مكتمل ويُبنى بضغطة واحدة في Android Studio.

## متطلبات
- أقل إصدار أندرويد: 7.0 (API 24). الهدف: API 35.
- أذونات: `TRANSMIT_IR` و `NFC` (تُمنح تلقائيًا، غير حساسة).

## حدود تقنية مهمة (اقرأها)
- **قراءة IR**: أندرويد **لا يوفّر أي API عام لالتقاط إشارات IR**. الواجهة الرسمية
  `ConsumerIrManager` للإرسال فقط. لذلك يعتمد التطبيق على: استيراد أكواد جاهزة +
  المسح التلقائي. القراءة الحقيقية تتطلب صلاحيات root ووجود مستقبل عتادي (نادر)،
  وقد أضفنا فحصًا يكشف ذلك تلقائيًا في تبويب IR.
- **NFC**: كل شيء متاح بلا root — القراءة والكتابة و APDU و HCE.

راجع `docs/REFERENCE.md` للتفاصيل الكاملة لكل واجهة برمجية.
